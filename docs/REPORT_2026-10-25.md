## Addendum, same day: character milestone

**Scope:** replace the procedural box character with a properly licensed rigged humanoid, verified in the running game.

### Completed and verified

- **Asset sourced and licensed.** Quaternius *Universal Animation Library* (Standard tier), CC0 1.0 as stated on the author's itch.io page; glTF obtained from the `J-Ponzo/gltf-universal-animation-library` mirror. Files, sizes, URLs and licence recorded in `docs/ASSET_REGISTER.md`; `LICENSE` committed next to the model.
- **Integration.** `PlayerMesh` now loads the glTF, finds the `AnimComposer` and `SkinningControl`, swaps the PBR materials for the scene's Phong materials tinted per character, scales the model to 1.72 m with feet at y = 0, and selects `Idle_Loop` / `Walk_Loop` / `Jog_Fwd_Loop` / `Sprint_Loop` / `Crouch_Idle_Loop` / `Crouch_Fwd_Loop` / `Jump_Loop` from the controller state, with clip speed scaled to movement speed. Public API unchanged, so `CompanionNPC` and `ProjectJulyApp` needed no structural change. `PlayerControl` passes the airborne flag. `assets/` is now registered with the asset manager via `FileLocator`.
- **Spawn facing.** Arif now spawns facing the Raju sculpture (heading 180°) instead of the camera.
- **Log hygiene.** The glTF loader's 3,405 "linear interpolation" warnings are silenced during the character load only; the run log dropped from ~3,500 lines to 106.
- **Evidence.** Build and 7/7 tests pass. Two 300-frame runs completed. `character_2026-10-25_spawn_v1.png` shows Arif and Rafi as mannequins in idle; `character_2026-10-25_spawn_v2.png` shows the jog clip mid-stride. The profile line prints `Character: model loaded=true, clip=Jog_Fwd_Loop, clip time=0.30 s`.

### Honest limits

- The mannequin has **no face, hair or clothing**. It satisfies "licensed, human proportions, suitable animation" and no longer fails the gate on primitive geometry, but it does not yet look like a student in shirt and jeans. A dressed model on the same rig is the next character task.
- During the second automated run, mouse and keyboard input reached the game window (camera yaw 280°, character displaced 8 m). This was not scripted. It happens to demonstrate locomotion, but the spawn-facing change is therefore verified only by code reading, not by that screenshot.
- Clip nominal speeds used to reduce foot sliding are estimates by eye, not published values.
- Talking idle during dialogue is wired in `PlayerMesh.setTalking` but not yet called from the dialogue flow.
- Static-run frame time on this Windows machine with four skinned characters: 21–26 ms average over 300 frames at 1280×720. Not a benchmark; not the target Mac.
